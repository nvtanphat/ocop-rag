### 3. Các lỗi còn lại và tác động đối với Full Run
1. **Ô điểm chữ số đơn lập trong bảng dày**: Tỷ lệ đọc sơ cấp đạt 90,3%, 9,7% còn lại được bắt trọn vẹn qua ứng viên `score_ocr_candidates` (đạt tổng 99,1%). Tác động: Hệ thống không mất im lặng bất kỳ ô điểm nào; người dùng có thể duyệt nhanh các ô điểm có sẵn đề xuất trong file Markdown `review/<source_id>/p###.md`.
2. **Lỗi chính tả OCR nhỏ (dấu thanh hoặc dấu đầu dòng)**: Dấu đầu dòng `+` đôi khi nhận thành `%`, từ `tiềm năng` thành `tiểm năng`. Tác động: Không ảnh hưởng đến cấu trúc đồ thị hay tính pháp lý vì RAG sử dụng tìm kiếm mờ ngữ nghĩa và chỉ trích dẫn các bằng chứng đã qua cổng xác minh.

### 4. Dự báo Full Run (583 trang: 315 scan + 268 native)
- **Tốc độ đo thật**:
  - Tốc độ scan thực tế: **94,89 giây/trang scan** (đo trên 48 trang scan ở lượt hai).
  - Tốc độ native: ~0,5 giây/trang.
- **Tổng thời gian OCR dự kiến**:
  - 315 trang scan x 94,89s = 29.890 giây ≈ **8,3 giờ**.
  - 268 trang native x 0,5s ≈ 134 giây (~2,2 phút).
  - Tổng thời gian chạy OCR full: **khoảng 8,3 đến 9,0 giờ** với 3 workers trên cấu hình máy hiện tại.
- **Dung lượng ổ đĩa cần thiết**:
  - Dataset thô & trang JSONL: ~35 MB.
  - Review Markdown & ảnh crop 150 DPI: ~190 MB.
  - Knowledge artifacts (thực thể, quan hệ, evidence units): ~25 MB.
  - Graph RAG & Qdrant vector index: ~40 MB.
  - 3 bản snapshot đồ thị: ~120 MB.
  - Tổng dung lượng vận hành ước tính: ~450 MB. **Khuyến nghị dành trống tối thiểu 2 - 4 GB** để đảm bảo không gian an toàn cho bộ đệm tạm thời (staging/cache).
- **Số lời gọi LLM ước tính**:
  - Đo trên 51 trang thí điểm có 104 khối tri thức chọn lọc (~2,04 khối/trang).
  - Ngoại suy toàn corpus 583 trang: khoảng **1.200 khối tri thức** cần semantic extraction.
  - Với cơ chế chia chunk và 4 workers đồng thời: ước tính khoảng **1.200 - 1.400 lời gọi LLM** (thời gian chạy extraction khoảng 1,5 - 2,0 giờ có cache).

### 6. Quy trình và lệnh chạy Full Run chuẩn (Người dùng thực hiện, Agent không tự chạy)
```powershell
# BƯỚC 1: Chạy OCR toàn bộ 583 trang (3 workers, ~8.5-9 giờ)
python -m ocop_ocr run --root D:/AgentAI/OCOP-RAG/OCOP_GRAPHRAG_CLEAN/OCOP-GraphRAG --dataset D:/AgentAI/OCOP-RAG/ocr-dataset-full --workers 3 --dpi 300

# BƯỚC 2: Xuất Markdown và ảnh 150 DPI phục vụ duyệt dữ liệu
python -m ocop_ocr export --root D:/AgentAI/OCOP-RAG/OCOP_GRAPHRAG_CLEAN/OCOP-GraphRAG --dataset D:/AgentAI/OCOP-RAG/ocr-dataset-full

# BƯỚC 3: Người dùng đối chiếu ảnh, sửa chữ trong review/<source_id>/p###.md, đổi 'trang_thai: da_duyet', sau đó nhập lại dataset
python -m ocop_ocr import --root D:/AgentAI/OCOP-RAG/OCOP_GRAPHRAG_CLEAN/OCOP-GraphRAG --dataset D:/AgentAI/OCOP-RAG/ocr-dataset-full

# BƯỚC 4: Xây dựng đồ thị RAG production từ dataset hoàn chỉnh đã được duyệt
python tools/cli.py run --ocr-dataset D:/AgentAI/OCOP-RAG/ocr-dataset-full --build-only
```
